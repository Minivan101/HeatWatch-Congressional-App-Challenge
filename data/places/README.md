# Las Vegas places

`las_vegas.json` has 13,989 named OSM records from an Overpass query on October 15, 2026. The query returned 14,004 records. We excluded 13 invalid or out-of-area records and 2 inactive entries. The count does not mean 13,989 separate, open businesses or checked entrances.

- Source: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright).
- Bounds: south 36.04, west -115.50, north 36.4015, east -115.04.
- Includes named amenities, shops, leisure, tourism, offices, healthcare and public transport. Being listed here does not make a place a cooling station.
- Records keep the OSM link, name, address, aliases, access tag and point precision. A feature center is not necessarily an entrance.
- Metadata keeps the query, source and retrieval times, response hash, counts and exclusions. No user location or search history is included.

Search matches names, aliases and addresses. Exact matches come first; distance from central Las Vegas breaks ties. Nearby records with the same name are grouped, while distant branches stay separate. Search returns up to 200 matches, shown 20 at a time.

If nothing matches, the app tries Photon. “Search online for more places” also uses Photon when local matches exist. Coordinates and map pins can select unlisted points, but they do not prove public access or create a walking connection. Routing still needs a connected, accessible path.
